Privacy Policy

This application ("Wayne's Mini Apps") uses the Google Calendar API to read and manage calendar events on your behalf. It is a personal-use tool intended solely for the original developer.

Data Handling

  • No personal data is stored, collected, or transmitted to any third party.
  • Google OAuth tokens are used only to fulfill requested calendar operations.
  • No analytics, tracking, or advertising services are used.
  • Calendar data accessed via the API is not logged, cached, or retained.
